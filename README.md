# School Multipliers India

A growth plan for a global student research olympiad in India: nine school networks and partners that could bring schools in, why each would say yes and the first ask, a school outreach playbook, a funnel model with labelled assumptions, a 90-day plan and the measures a board would see.

Static HTML, CSS and JavaScript with no build step. Facts live in `assets/data.js`, each with its source, checked 31 Oct 2026. Priorities, asks, messages and funnel inputs are proposals, not facts about any organisation.

Independent work built from public sources. Not affiliated with or endorsed by any organisation named.
